# 恶魔bot (astrbot_plugin_demonbot)

AstrBot 群聊拟人插件。自维护、自包含，不依赖其他插件。

## 功能

| 模块 | 作用 |
|---|---|
| `peak_hours` | **高峰时段省钱**：北京时间 9:00-12:00、14:00-18:00 接口双倍计费，这两段时间 bot 不主动插话、不做任何后台请求；被 @ 时仍会回但有冷却 |
| `token_saver` | **上下文瘦身**：限制每次请求带多少历史对话、单条多长、人格提示词多长。这是账单里最大的一块 |
| `commands` | 自建指令分发（30 条指令，群聊私聊通用），不走框架 command 装饰器，保证 `/指令` 不会被当成聊天喂给模型 |
| `knowledge` | 联网学新梗：检测到没见过的词自动搜索 → 归纳释义 → 存入本地词库 → 注入当次回复。附带热搜抓取 |
| `images` | Pixiv 系插图 + 真人图：四档画质（原图/高/中/低，默认「高」）、按人计的发图冷却（默认 5 分钟，管理员豁免）、全年龄/擦边分区 |
| `members` | 群友编号档案：每群独立编号、别名、发言量、备注；注入当前发言人身份，避免认错人 |
| `style` | 说话风格自学习：定时用 LLM 归纳群里真实打字习惯 |
| `reply_style` | 回复清洗与长度硬控：去 markdown、去「昵称: 时间戳」前缀、去客服式收尾、砍成一句话、思考延迟 |
| `reply_gate` | 插话时机：@必回 + 管理员/白名单概率 + 关键词/情绪词/冷场判断，可切 LLM 判断模式 |
| `end_talk` | 收到「嗯嗯/好的/哦哦」这类收尾语时闭麦并短时静默 |
| `mute` | 本地闭嘴指令 + QQ 平台禁言(retcode 1200)自动退避，管理员一句话强制全清 |
| `repeat` | 复读链跟风 |
| `segment_reply` | 长回复分段（默认关）。开启时由 `after_message_sent` 保证顺序 |
| `mood` | 心情值系统，只影响语气，默认不播报当前活动 |
| `media_skip` | 含图片/视频时在请求 LLM 之前拦下 |

LLM 工具：`lookup_slang` `search_web` `remember_slang` `lookup_member` `note_member` `query_group_chat_history` `demon_remember` `demon_recall`

## v2.4.0 省钱改动

用量表显示，账单涨的不是"回复变长"，而是**单次请求的输入 token**：
从 1.7k/次 一路涨到 33.8k/次。原因是每次请求都会把整段会话历史重新上传一遍。

针对性做了四件事：

| 改动 | 效果 |
|---|---|
| 上下文裁剪（`token_saver`） | 每次最多带 6 条历史、单条 120 字、人格 1200 字。实测单次请求体积降到原来的 11% |
| 高峰时段闭麦（`peak_hours`） | 双倍计费的 7 小时里不主动开口、不跑后台任务 |
| 后台请求预算 | 学风格/查梗/插话判断这些用户看不见的请求，每天封顶 60 次，高峰期一律推迟 |
| 提示词压缩 | 输出约束从 430 字压到 150 字，群友名单改成"聊到人才带" |

**注意**：原图画质和 GitHub 拉插件都**不消耗 token**——图片是把 URL 交给 QQ 下载，
拉插件走的是 GitHub。改画质省的是流量和发图速度，不是钱。

### 常用开关

```
/开关                 看全部分级指令
/开关 分辨率 中        插图画质：原图 / 高 / 中 / 低
/开关 图冷却 300       普通用户每 5 分钟才能要一张图（管理员不受限）
/开关 真人图 关
/开关 回复群友 关      只搭理管理员
/开关 发言 关          总开关，除指令外一个字都不说
/省钱                 看现在为什么不说话、今天省了多少
```

## 容错设计

子模块（`websearch.py` / `images.py` / `tools/`）采用降级导入：任一文件缺失或报错时，
只停用对应功能，插件本身照常加载，指令与聊天不受影响，`/自检` 会列出具体原因。

## 安装

把整个文件夹放进 `AstrBot/data/plugins/`，WebUI → 插件管理 → 重载插件。

文件清单：`main.py` `websearch.py` `images.py` `__init__.py` `_conf_schema.json`
`metadata.yaml` `requirements.txt` `tools/`（5 个文件）——缺一不可。

## 配置要点

- `reply_gate.admin_ids`：管理员 QQ 号，管理员专属指令依赖此项
- `reply_style.self_names`：bot 昵称，用于剥离自称前缀
- `reply_gate.gate_provider_id`：查梗、风格学习、插话判断使用的模型，建议指向便宜的小模型
- `knowledge.backends`：搜索后端顺序，先用 `/联网测试` 确认哪些可用
- `images.keyword_map`：中文词到 Pixiv 日文标签的映射，直接决定出图质量

## 指令

前缀 `/` 或 `==`，群聊私聊均可。发 `/帮助` 看完整列表。

| 分类 | 指令 |
|---|---|
| 基础 | `/帮助` `/状态` `/自检` `/版本` |
| 词库 | `/梗` `/教梗` `/忘梗` `/词库` |
| 联网 | `/搜` `/联网测试` `/热点` |
| 插图 | `/图` `/图源测试` `/标签` `/上一张` `/age>18` `/age<18` |
| 群友 | `/群友` `/查人` `/备注` `/忘了他` |
| 人格 | `/学风格` `/风格` `/重置风格` `/心情` |
| 记忆 | `/记住` `/回忆` |
| 控制 | `/闭嘴` `/解禁` `/冷却` `/概率` `/开关` |

插件异常时先发 `/自检`。
